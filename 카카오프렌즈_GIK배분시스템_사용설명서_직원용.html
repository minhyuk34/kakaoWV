카카오프렌즈
GIK배분시스템
월드비전 내부 직원 전용 카카오프렌즈 GIK제품 배부 신청 및 관리 시스템입니다.
🔒 내부 전용 — 외부 유출 금지 📅 2026년 7월 기준
1
시스템 소개

카카오프렌즈 GIK배분시스템은 월드비전 내부 직원이 카카오프렌즈 GIK(현물기부) 제품을 신청하고, 담당 관리자가 승인·배부를 처리하는 내부 관리 플랫폼입니다.

🛍️
제품 카탈로그
144종 카카오프렌즈 제품을 카테고리별로 검색하고 장바구니에 담아 한 번에 신청
✅
승인 워크플로
신청 → 관리자 승인 → 배부 순서로 처리되며 각 단계별 이메일 알림 발송
📦
실시간 재고 관리
신청 즉시 재고 차감, 취소 시 자동 복구. 관리자는 전체 재고 현황 실시간 확인 가능
📊
배부현황 리포트
제품×팀 피벗 표로 어디에 몇 개 나갔는지 한눈에 파악, 구글 시트 자동 생성
🔒 내부 전용 시스템입니다. 접속 URL을 외부에 공유하거나 스크린샷을 외부로 유출하지 말아주세요.
2
계정 만들기 · 로그인

처음 사용하는 경우 회원가입이 필요합니다. 이름과 비밀번호만 설정하면 바로 사용할 수 있습니다.

1
시스템 접속
관리자로부터 전달받은 URL로 접속합니다. 로그인 화면이 표시됩니다.
2
회원가입 클릭
처음 이용 시 로그인 화면 상단의 회원가입 탭을 클릭합니다.
3
정보 입력
이름(실명), 이메일(업무용), 비밀번호를 입력하고 가입하기를 클릭합니다. 이름은 신청서에 그대로 표시되므로 실명으로 입력해주세요.
4
로그인
가입한 이름과 비밀번호로 로그인합니다. 이후부터는 같은 계정으로 접속하면 됩니다.
💡 비밀번호는 암호화되어 저장되므로 관리자도 확인할 수 없습니다. 분실 시 관리자에게 계정 재생성을 요청하세요.
3
제품 목록 보기

로그인하면 카카오프렌즈 제품 카탈로그 화면이 표시됩니다. 144종 제품을 카테고리, 재고 여부로 필터링하거나 이름으로 검색할 수 있습니다.

1
검색 / 필터
상단 검색창에 제품명 또는 번호를 입력합니다. 전체 제품 / 재고 있음 필터와 카테고리 드롭다운으로 원하는 제품을 빠르게 찾을 수 있습니다.
2
재고 확인
각 카드의 재고 숫자를 확인합니다. 재고가 0인 제품은 목록에 표시되지 않습니다. 필요한 경우 관리자에게 재고 추가를 요청하세요.
3
제품 이미지 확대
제품 이미지를 클릭하면 크게 볼 수 있습니다.
4
신청하기

원하는 제품을 장바구니에 담은 후 신청 정보를 입력하여 배부 신청을 완료합니다.

1
수량 입력 후 장바구니 담기
제품 카드에서 신청할 수량을 입력하고 장바구니 담기 버튼을 클릭합니다. 여러 제품을 한 번에 담을 수 있습니다.
2
장바구니 확인
상단 📋 장바구니 버튼을 클릭합니다. 담긴 제품 목록과 합계 금액을 확인합니다.
3
상세사업 입력 (필수)
각 제품 아래 상세사업 입력란(노란 테두리)에 사용 목적을 구체적으로 입력합니다. 예: "아동 직접 배부용(후원자대상 성탄캠페인)"
4
신청 정보 입력
본부, 팀, 이름, 연락처(자동 하이픈 처리), 이메일, 사용처, 수취 예정일, 사용 예정일을 입력합니다.
5
배부요청 완료
배부요청 버튼을 클릭하면 신청이 완료됩니다. 재고가 즉시 차감되고 관리자에게 신청 내역이 전달됩니다.
✉️ 관리자가 신청을 승인하면 입력하신 이메일로 승인 알림 메일이 자동 발송됩니다.
5
주문내역 확인

상단 주문내역 탭에서 내가 신청한 모든 건의 현황을 확인할 수 있습니다.

⏳ 대기중 ✅ 승인완료 📦 배부완료 ⏳ 취소신청중 ✕ 취소됨
상태의미가능한 행동
대기중관리자 검토 전항목별 취소 가능
승인완료관리자 승인, 배부 준비 중항목별 취소신청 가능
배부완료제품 배부 완료배부처 기록, 결과보고서 파일 등록 가능
취소됨신청 취소 처리—
📎 배부완료 상태에서는 결과보고서 등록 버튼이 표시됩니다. 명단(엑셀)과 보고서(PDF/Word)를 업로드하면 구글 드라이브에 자동 저장됩니다.
📍 배부처 기록 남기기

배부완료된 항목마다 실제로 어디에 몇 개를 나눠줬는지 직접 기록할 수 있습니다. 제품명 · 수량 · 배부처 · 배부수 · 남은개수 순서의 표로 표시됩니다.

1
배부처 · 배부수 입력
배부완료된 항목 아래 표에 배부처(예: OO팀, OO기관)와 그곳에 나눠준 수량을 입력합니다.
2
필요하면 행 추가
여러 곳에 나눠줬다면 + 행 추가 버튼으로 줄을 늘립니다. 품목당 최대 10줄까지 기록할 수 있습니다.
3
남은개수 확인 후 저장
입력한 수량의 합계만큼 남은개수가 자동으로 줄어듭니다. 0이 되면 초록색으로 표시됩니다. 다 입력했으면 💾 저장을 클릭합니다.
📥 주문내역 상단의 엑셀 다운로드 버튼을 누르면 신청 정보와 배부처 기록을 포함한 전체 주문내역을 CSV(엑셀) 파일로 받을 수 있습니다.
6
취소 신청

신청 상태에 따라 취소 방식이 다릅니다. 취소 시 해당 수량은 재고에 자동 복구됩니다.

🕐
대기중 상태 — 즉시 취소
주문내역의 각 항목 옆 항목취소 버튼을 클릭하면 즉시 취소됩니다. 재고가 바로 복구됩니다.
✅
승인완료 상태 — 취소신청
각 항목 옆 취소신청 버튼을 클릭합니다. 관리자에게 취소 요청이 전달되며 ⏳ 취소신청중 상태로 변경됩니다. 관리자가 확정해야 최종 취소됩니다.
💡 배부완료 상태에서는 취소가 불가합니다. 관리자에게 직접 문의하세요.
7
피드백 남기기

상단 💬 피드백 탭에서 시스템 이용 후기나 개선 의견을 남길 수 있습니다.

1
별점 선택
★☆☆☆☆ ~ ★★★★★ 중 만족도에 맞게 선택합니다.
2
분류 선택
UI/디자인, 기능, 속도, 오류, 건의사항, 기타 중 하나를 선택합니다.
3
의견 작성 후 제출
자유롭게 의견을 작성하고 피드백 제출을 클릭합니다. 내용은 구글 시트 "피드백" 탭에 저장되며 관리자가 확인합니다.
📌
신청 상태 한눈에 보기
상태설명유저 가능 행동관리자 가능 행동
⏳ 대기중신청 접수, 관리자 검토 전항목 취소항목/전체 승인, 반려, 전체취소
✅ 승인완료관리자 승인, 배부 대기항목 취소신청항목/전체 배부, 취소확정/거절
📦 배부완료실물 배부 완료결과보고서 등록—
❌ 반려관리자 반려 처리재신청 가능—
✕ 취소취소 완료——
❓
자주 묻는 질문
Q
원하는 제품이 목록에 없어요.
재고가 0인 제품은 일반 직원 화면에서 표시되지 않습니다. 관리자에게 재고 추가를 요청하세요.
Q
연락처에 하이픈(-)을 꼭 넣어야 하나요?
아니요. 숫자만 입력해도 자동으로 000-0000-0000 형식으로 변환됩니다.
Q
승인 이메일을 못 받았어요.
회원가입 시 입력한 이메일 주소를 확인해주세요. 스팸함을 확인하거나, 관리자에게 이메일 재전송을 요청할 수 있습니다.
Q
비밀번호를 잊어버렸어요.
비밀번호는 암호화 저장으로 복구가 불가합니다. 관리자에게 계정 재생성을 요청하세요.
Q
결과보고서는 어디에 저장되나요?
관리자 구글 드라이브에 자동 저장됩니다. 신청 상세 페이지의 관리자 메모 칸에서 링크를 확인할 수 있습니다.
